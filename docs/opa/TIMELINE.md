# Saved activity timeline

Campus → Timeline reads the bounded local event index introduced in [Event History](EVENT_HISTORY.md). Choose one project; requests never aggregate unrelated project histories. A task's **View recorded activity** opens its task filter, with the selected run filter when viewing a saved attempt.

The timeline loads 20 observations at a time, newest first by durable host ordinal. Load older events appends deduplicated pages; Refresh replaces the window. Reconnection reloads the current route's window, without replaying task commands. Loaded evidence remains readable offline. Request results from an unmounted route or superseded connection are ignored. The retained server window and client list are bounded to 2,000 observations.

Filters for task, run, provider, session and event type are committed with Apply filters. All filters and an optional selected event ordinal round-trip in credential-free version-1 hash links. Inspect event opens its stored details; a link to an event anchors the first page just before that ordinal plus one. Return to newest removes the anchor. Missing, retained-away, future or filtered-out targets report unavailable instead of substituting a different event. These links are host-local: the ordinal identifies this host's index, not a global event ID. Historical projects remain queryable by their exact path in a saved link after their live projection disappears.

Each row shows source timestamp, host observation timestamp, provider/session/agent/stream and per-stream sequence, captured task/run association, and source provenance. Test fixtures are labelled. Ordinals preserve host observation order; source clocks may be skewed, and adjacency across streams does not establish causality. Filters can hide intervening events. The global retention prefix is shown explicitly and is not interpreted as a per-project event count. Missing task/run associations remain Unknown. No events, task completions or check outcomes are inferred from other records.

Excerpts and details contain only the index's retained allowlisted fields; truncation is labelled. React escapes recorded content. Source journals remain necessary for complete original payloads. Open task / attempt navigates to the saved summary where an association exists; Open session context navigates to the source identity and can report unavailable if that live projection has ended. None of these actions starts, retries, stops or approves work, changes task status, replays events, or acknowledges the Inbox. Existing host authentication and permission boundaries are unchanged.

English and Russian labels are included. No backend protocol or storage migration is added in this increment. See [Deep Links](DEEP_LINKS.md) and [TaskRun History](TASK_RUNS.md) for existing navigation and evidence boundaries.
